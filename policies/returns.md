# Standard returns

Northstar Supplies accepts a standard return request within 30 calendar days of the recorded delivery date. The order must belong to the authenticated customer and have status `delivered`.

# Review threshold

Support agents may draft the standard return route for orders worth £100 or less. Higher-value orders require human review. Eligibility means the request can be reviewed; it is not confirmation that money has been refunded.
